## 排障：智谱 Key 报「未配置向量化模型密钥」（20:18 前后）

- 根因有二：① 用户把密钥直接写进 `.env.example`，而 Next 只加载 `.env.local`/`.env`；② 该密钥本身无效（32 位无点号，智谱接口对 chat 与 embedding 都返回 401「令牌已过期或验证不正确」，智谱 Key 形如 {id}.{secret}）。
- 修复：把密钥迁到 `.env.local`、`EMBEDDING_MODEL` 改为 `embedding-3`、`.env.example` 还原为占位模板。
- 代码增强：`lib/config.ts` 增加 `guessEmbeddingModel`（按 BASE_URL 推断默认向量模型：bigmodel→embedding-3、siliconflow→bge-m3、dashscope→v3、ollama→nomic）与 `diagnoseEnv()` hints；health/documents 接口和聊天页横幅会展示具体提示；ingest 的 401/404/429 错误翻译成中文结论。
- 新增 `npm run doctor`（scripts/doctor.ts）：一键检查 env 文件、chat 401/404、Function Calling 支持、embedding 维度、本地索引。
- 教训：这类「配置读不到」问题别猜，先看磁盘上的 .env* 实际内容；doctor 式自检脚本能把排障从来回猜变成一条命令。
